Catalog icons and screenshots are upstream projects' own brand marks,
vendored verbatim so the public catalog loads every subresource
same-origin (#716 — a hotlinked icon whose host hangs stalls the
page's load event). Provenance for each icon lives in the matching
provenance comment beside its `icon_url` in
`apps/platform/priv/repo/seeds/catalog_data.yaml`. These files are
the projects' marks used to identify the catalogued apps, not covered
by the repository's FSL license.
